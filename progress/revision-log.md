# Revision Log

Spaced repetition schedule per problem and topic. See
[`roadmap/learning-roadmap.md`](../roadmap/learning-roadmap.md).

**Schedule:** Day 0 (learn) → Day 3 (recall) → Day 7 (re-solve) → Day 21 (revisit) → Day 45 (timed)

Recall drills do not always require full re-implementation. Valid prompts:

- What is the pattern?
- What is the invariant?
- Time and space complexity?
- What changes if input is sorted?
- What if memory is limited?
- What if data is streaming?
