# Changelog

All notable changes to this handbook are documented here.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/).

## [0.2.0] - 2026-09-07

### Added

- Problem write-ups for the five interactively studied problems: Contains Duplicate, Two Sum, Best Time to Buy and Sell Stock, Top K Frequent Elements, Longest Substring Without Repeating Characters.
- Pattern pages authored from those lessons: HashMap/HashSet, two pointers (sorted pair), sliding window, heap / PriorityQueue.
- Revision compression: pattern cheatsheet (learned rows only), Java idioms (`add` return, `getOrDefault`, bounded heap), complexity notes (average-case hash, monotonic nested loops), study-specific common mistakes.

### Changed

- Progress tracker, revision log, problem index, learning roadmap, and README to reflect documented work — next focus is two pointers as a first-class pattern.

## [0.1.0] - 2026-08-22

### Added

- Initial repository structure for the DSA Interview Handbook.
- Root `README.md` with philosophy, schedule, and usage guide.
- Roadmap: learning order, interview strategy, curated problem index (~60 problems).
- Progress tracker and revision log with spaced-repetition schedule.
- `STYLE_GUIDE.md` — contracts for pattern and problem documents.
- Templates for patterns and problems.
- **Module 0** — `fundamentals/complexity.md` (Big-O and problem-solving fundamentals).
- **Module 1** — `fundamentals/arrays.md` (arrays as a foundation; no problems yet).
- Revision cheatsheets and interview communication templates (scaffolds).
- Placeholder stubs for patterns, data structures, and algorithms (authored progressively).
